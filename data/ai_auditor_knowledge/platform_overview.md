# Platform Overview\n\n**AI Auditor V0.1** is a tool designed to evaluate AI systems for potential risks such as bias, fairness, privacy, security, and more. It provides an interactive web interface where users can start audits, view results, explore audit categories, and learn through the School Project section.\n\nThe platform consists of the following main sections:\n\n- **Start Audit** – Create a new audit by entering a prompt, model, system description, or test case.\n- **Audit History** – Review past audits and their outcomes.\n- **Audit Results** – Detailed findings for a completed audit.\n- **Audit Categories** – Explanations of each risk category (e.g., Fairness, Bias, Privacy).\n- **School Project** – Educational resources and example projects.\n- **FAQ** – Frequently asked questions about the platform and auditing process.\n- **Help / AI Assistant** – Interactive assistant that guides users through the platform.\n\nThe assistant should be able to explain each of these sections and guide users step‑by‑step.
