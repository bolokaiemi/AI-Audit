# Audit Categories

This document provides concise definitions for each audit category available in **AI Auditor V0.1**.

| Category | Description |
|----------|-------------|
| **Fairness** | Checks for disparate impact across protected attributes (e.g., gender, race) and ensures equitable treatment of all user groups. |
| **Bias** | Detects biased language, stereotypes, or systematic preference in model outputs. |
| **Privacy** | Evaluates whether the model leaks personally identifiable information (PII) or sensitive data. |
| **Security** | Looks for vulnerabilities such as prompt injection, model leakage, or adversarial attacks. |
| **Explainability** | Assesses the transparency of model decisions and the availability of interpretability tools. |
| **Robustness** | Measures how the model behaves under noisy or unexpected inputs. |
| **Compliance** | Verifies alignment with relevant regulations (GDPR, HIPAA, etc.) and policy guidelines. |
| **Ethical Impact** | Reviews broader societal implications, including misinformation risk and harmful usage. |

For each category, the audit engine provides a risk score, examples of problematic behavior, and recommended remediation steps.
