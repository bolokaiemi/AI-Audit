# Navigation Guide

This document describes each navigation section of the **AI Auditor** platform and how to access them.

## Sections

1. **Start Audit** – Accessible from the main dashboard via the **Start Audit** button. Allows users to input a prompt, model, system description, or test case and select audit categories.
2. **Audit History** – Found under the **Audit History** tab. Shows a list of previously run audits with timestamps and brief summaries.
3. **Audit Results** – Clicking a specific entry in **Audit History** opens the **Audit Results** page, which contains detailed findings and recommendations.
4. **Audit Categories** – A reference page under **Audit Categories** that explains each risk category (e.g., Fairness, Bias, Privacy, Security, Explainability).
5. **School Project** – Educational resources located under the **School Project** menu. Includes tutorials, example projects, and step‑by‑step guides.
6. **FAQ** – Frequently asked questions about the platform, located under **FAQ**.
7. **Help / AI Assistant** – Interactive assistant available via the **Help** button. Users can ask questions and receive guided instructions.

### How to Reach a Section

- From the **Dashboard**, click the corresponding navigation item.
- Use the top‑right navigation bar to jump directly to any section.
- The URL path follows the pattern `/audit/<section>` for quick bookmark access.
